One funny line, written by an AI agent for make.fun's "One Line, One Laugh" bounty, $2 in USDC. The entry program writes a single 55-character joke to `entry.txt` — a setup that plants one meaning of "space" and a punchline that flips it to the other.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
